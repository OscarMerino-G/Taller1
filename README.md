# Reproductor de musica :trollface:
## Integrante
Oscar Merino

El proyecto
> El proyecto es un reproductor de música que carga la configuracion del mismo y la lista de canciones desde un archivo. Tiene las funciones básicas de un reproductor de música (saltar canción y volver a la canción anterior) y tiene las funciones que se encuentran en los servicios de streaming de musica (cola de canciones, crear lista de canciones e historial de canciones)
